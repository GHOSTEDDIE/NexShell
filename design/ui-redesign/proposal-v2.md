# NexShell 左侧双页签设计稿

本轮仅修改设计稿。以当前 `internal/ui/app.go`、`desktop.go`、`monitor.go` 的实际布局与采集能力为依据：左侧目前承载活动服务器状态，连接列表位于中央工作台页；状态随活动终端标签更新。

左侧固定两个页签：服务器状态、连接列表。中间终端与文件区、右侧助手沿用方案 01。

- 服务器状态：展示当前活动终端所属服务器的名称、地址、连接状态、最近更新时间、处理器、负载、内存、磁盘、网络、系统信息；进程与端口连接以可展开入口呈现。示例数值用于视觉确认。
- 连接列表：展示搜索、分组、连接名称、地址、当前活动连接和新建/导入入口。沿用已有的单击选择、双击连接语义；已打开的连接应优先切换到对应会话。
- 切换左侧页签不会中断连接，也不会改变中央活动会话。切换中央终端时，服务器状态跟随更新；若用户正在浏览连接列表，保留该页签，避免突然跳转。
- 未连接时仍可访问两个页签；服务器状态页显示“连接服务器后，在此查看运行状态”及“查看连接列表”入口。采集失败须清晰显示失败或数据已过期，不显示为正常状态。

两张完整设计稿分别用于确认两个页签的选中状态。尚未实现客户端改版。
