# NexShell HTML 设计预览

入口：`nexshell-prototype.html`，单文件，可直接在浏览器打开。本轮延续已确认的工作台布局，统一从设置入口访问外观和模型配置；未修改正式客户端功能。

## 导航

- “设置 → 外观与显示”：亮色、暗色、跟随系统。默认跟随系统，监听浏览器的系统配色变化；显式选择亮色或暗色时不受系统变化影响。
- 右上角“设置”：外观与显示、模型配置。助手输入区的齿轮也可直接进入模型配置。
- 外观页可调整界面文字整体大小和独立的终端文字大小；外观修改即时生效。
- 模型配置沿用当前 `internal/ui/app.go` 的接口类型、服务地址、模型名称、密钥、上下文容量字段。支持 OpenAI 兼容接口与 Ollama；上下文容量至少 4096。

## 预览边界

配置仅存在于当前页面内存。模型表单“应用到预览”更新示例模型选择器，不调用服务、不写入客户端配置、不持久保存密钥。页面刷新恢复示例状态。

亮色工作台继续保留深色终端；暗色覆盖工作台、表单、设置窗口和系统原生控件配色。左侧双页签、CPU 与内存状态、终端会话切换沿用上一版设计。
