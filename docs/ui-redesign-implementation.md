## 已实现

- 左侧服务器状态 / 连接列表小型下划线页签；活动终端切换不会抢占左侧页签选择。
- 左侧从真实采集结果展示 CPU、内存、磁盘、网络、系统和运行时间；采集失败时清除过期数值并明确标识，不将失败显示为零占用。
- 三栏工作台：左栏 248、助手 340；宽窗口采用 264 / 372，终端区使用剩余空间。助手可收起；文件、传输和网络诊断保留在终端下方。
- 统一 18 / 14 / 13 / 12 字号层级，普通界面使用比例字体和中等字重，终端使用等宽字体并保留中文。
- 顶部仅显示设置入口和助手开关。亮色、暗色、跟随系统统一在设置中；界面字号、终端字号分别持久化。
- 模型配置沿用既有存储和系统凭据保管方式；接口类型、地址、模型名、密钥、上下文容量可实际保存，保存后同步刷新助手模型选择器。
- 助手按用户消息、回复、执行记录和验证结果显示真实事件；保留任务历史、审批、暂停和恢复入口。输入支持 Enter 发送、Shift+Enter 换行。
- 文件列表展示名称、大小和修改时间；原有上传、下载、权限、压缩、删除、目录跟随等操作保留在工具栏和菜单中。
- 继续保留原有终端关闭释放、文件目录跟随、增量任务历史、传输路由等逻辑。批量执行、端口转发、快捷命令位于应用的工具菜单。
