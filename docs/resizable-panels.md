# 四区可拖拽布局

左侧服务器区与中间终端、中间终端与右侧助手、终端与底部工具区之间各有一条可拖拽分隔线。分隔线提供 8 像素操作区域、方向对应的缩放光标和悬停高亮。拖动一侧时保留另一侧宽度，中间终端占用剩余空间。

拖拽结束后保存左右宽度与底部高度，重新打开应用恢复；助手隐藏时释放右侧空间，重新打开后恢复宽度；已有服务器标签在选中时应用最后保存的底部高度。主窗口缩小时调整尺寸，保留必要的最小空间并避免区域重叠。

连续调整尺寸还暴露并修复了旧问题：原实现为每次终端尺寸变化启动独立网络调用，慢的旧请求可能最后完成，覆盖新尺寸。现在单独按顺序发送尺寸更新，繁忙时只保留最新待发送尺寸，不阻塞终端输入，也不堆积后台请求。

验证包括实际鼠标拖拽命中、三个方向的尺寸变化、另一侧尺寸保持、边界限制、偏好保存、助手隐藏与恢复、标签切换和缩小主窗口。慢速远端模拟中，原实现最终错误地恢复为 18 行，修复后保持最新的 27 行。全项目并发回归、静态检查及本地隔离 Linux 集成测试通过。
