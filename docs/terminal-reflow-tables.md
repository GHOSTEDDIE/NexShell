# 终端窗口重排与表格查看

2026-09-11

## 修复与使用

终端视图原先在更新行列数之前触发绘制，因此拖动窗口后仍可能显示旧网格，直到收到下一次输出才更新。现在先更新终端尺寸，再绘制新网格；继续使用原有有序队列发送远端窗口尺寸变化。

底层主屏幕原先直接裁剪超出新尺寸的单元格。现在记录自动换行位置，将普通输出及历史记录重新排入新宽度，保留显式换行、中文宽字符、组合字符、颜色和光标位置。默认字号仍为 12，用户选择的字号不会被窗口拖拽改写。全屏程序的备用屏幕继续采用网格布局，由程序响应尺寸变化重新绘制；自定义滚动区域也保持原有网格行为。

运行 `docker ps` 等命令后，点击终端工具栏的“表格查看”，可查看当前终端最近一份具有对齐表头的表格。表格支持固定表头、横向滚动、选中单元格查看完整内容、复制单元格及复制整表。识别按表头的显示列位置切分数据，保留空列和字段内部连续空格，不重新执行命令。识别范围是大写或中文表头、至少两列、列间至少两个空格的对齐文本，不覆盖所有命令的自定义输出格式。

自定义对话框增加主题背景层，避免表格区域继承弹窗底层颜色后文字对比不足。
