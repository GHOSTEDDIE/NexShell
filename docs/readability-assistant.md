# 终端可读性、背景图与助手纠错

## 改动

- 调整标准 16 色 ANSI 前景色，修复目录蓝色、压缩包红色在深背景下几乎不可读的问题。保留扩展色和真彩色，终端默认字号仍为 12。
- 设置 → 外观与显示 → 终端背景：选择或替换 PNG/JPEG、移除图片、调节强度。图片经验证后原子保存到应用数据目录，重启恢复，现有和新建终端共同应用。默认淡化显示，强度上限用于保护文字可读性；程序显式背景、选中和反色继续有效。
- 助手回复复用 Fyne Markdown 解析器，支持流式更新后的标题、强调、列表、代码块和表格；用户输入和执行记录保持原文。
- 参数格式错误、验证证据不匹配、无效服务器编号等可纠正问题返回结构化工具反馈，模型可修正参数或获取新的只读证据后继续。反馈记入执行记录。相同失败达到三次后要求更换诊断方法；整体仍受原有迭代上限限制。
- 旧失败或中断对话中缺失的工具返回补记为“未获得结果”，保留已有证据，支持后续继续对话；不会推断工具已成功，也不会重放变更操作。
- 授权中断、取消、持久化故障和执行结果不明继续保留原控制流程。无法恢复时显示可理解的提示，详细错误放入执行记录。自动纠错不等于保证所有模型或网络错误都能自行解决。

## 验证

- 修改前重现目录蓝色对比度 1.04、红色 1.52，以及 Markdown 单一纯文本段和截图中的 verify_execution 终止错误。
- 最终 ANSI 前景色在纯色背景及最大强度的白色背景图上，对比度均至少 4.5。
- 真正经过流式助手、工具节点、持久化事件的回归验证：错误预期 → 工具反馈 → 正确证据 → verified 事件。
- 覆盖正常工具参数、空参数、分片 JSON、错误字段类型、重复错误提示、取消和不可恢复错误保留。
- 背景图解析、恢复、透明图层、显式背景和移除均通过回归；已有正常对话历史保持不变，历史补记可重复执行且不会重复添加。
- `go test -race -tags ci ./...`、`go vet -tags ci ./...` 均通过。
- 本地隔离 Linux 集成测试九项通过，包含授权执行、未知结果不重放、SSH/SFTP、转发和终端交互。

输出与界面渲染位于 `docs/evidence/readability-assistant/`。测试使用模拟模型和本地隔离服务器；没有调用用户真实模型，也没有修改用户远程服务器。
