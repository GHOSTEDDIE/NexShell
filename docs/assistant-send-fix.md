# 智能助手首次发送闪退修复

默认模型的持久化标识是 `default`，长度为 7。首次发送会进入新对话窗口，原代码直接读取 `p.ID[:8]`，在构建模型选项时触发越界并使进程退出。该错误发生在模型请求之前。

界面统一使用按实际长度截取的标识缩写函数，同时修复服务器、跳板机和历史对话中的同类截取。缩写只用于展示，持久化标识、模型选择映射和凭据引用保持原值。

回归覆盖默认模型与原有长标识模型，分别通过真实输入框回车和发送按钮进入首次对话流程，并验证短服务器标识以及确认前的草稿保留。测试使用临时数据库，没有请求真实模型或连接服务器。

验证：

- 修改前测试稳定重现 `slice bounds out of range [:8] with length 7`。
- 修改后发送入口回归通过，并开启并发检查。
- `go test -race -tags ci ./...` 通过。
- `go vet -tags ci ./...` 通过。

完整输出位于 `docs/evidence/assistant-send-fix/`。本地应用由 `scripts/package.sh` 重新打包；已启动的旧进程需要重新打开应用才能加载修复。
