# 连接主页与文件区

主页列出全部已保存连接，包括名称、账号、地址、端口和分组，单击选中、双击连接，也可使用连接和编辑按钮。保存、导入和删除后更新；搜索位于主页，清空搜索后显示全部连接。主页标签常驻，便于返回连接列表。

将一个或多个本机普通文件拖入当前标签的文件区即可上传。新文件直接进入已有传输队列，目标重名时选择覆盖或校验续传。拖入其他区域、其他工具页不会上传。队列记录拖入时的目标目录，后续切换标签或目录不改变目标。新文件使用排他创建，防止排队期间出现的同名文件被意外覆盖。目录需先打包后上传。

文件区初始目录来自当前 Linux 终端的实际工作目录，默认勾选“跟随终端目录”。每秒读取一次对应登录 shell 进程的 `/proc/<pid>/cwd`，终端执行 `cd` 后更新；分屏按焦点选择终端。可以关闭跟随以独立浏览文件。无法访问进程目录时显示“终端目录不可用”，支持手工指定目录，不把猜测路径当作当前路径。

验证：全项目竞争检测回归通过；隔离 Linux SSH 实测初始 `/root`、`cd /tmp` 后目录同步、同一终端环境保留、新文件上传及同名保护。原有 SSH、跳板、隧道、文件校验续传、ZMODEM、Agent 审批修复场景通过。主页已生成并查看渲染图；本轮未进行操作系统文件拖拽的人工实机验收。

## 服务器状态位置

服务器状态位于左侧，随所选终端标签切换；主页显示连接后的状态提示。处理器、内存、系统、负载、磁盘、网卡、进程和端口数据复用原监控组件及采集周期。底部不再展示监控标签，保留文件、传输与网络诊断。关闭终端后停止该会话的采集，采集失败时标记数据过期。

本次布局回归覆盖单击不连接、双击仅触发一次、列表行复用后目标正确、服务器状态随标签切换以及关闭后不显示旧状态；已有终端与监控测试通过。

## 磁盘表格

左侧首次采样无数值时显示“—”，不显示等待采样说明。磁盘占用独立显示为带固定表头的表格：挂载点、占用率、可用、已用、总量。容量自动换算单位，窄侧栏可横向滚动查看其余列；点击磁盘行可查看完整挂载路径及文件系统，刷新保留选择。采集失败清空磁盘行并显示错误状态，避免将过期数据当作当前占用。

解析测试保留 `df -Pk` 报告的占用率和可用容量，不通过总量减已用推算；覆盖保留块、包含空格的挂载路径、零占用、负可用容量、超过 100% 的占用和无效数据。已有处理器、内存和网络采集样本一并回归。
