# 界面对齐、字号与监控表格修复

## 修复内容

- 移除工作台、页签、文件区和设置窗口边界上的隐式间距；页签内容起点由 42 修正为 38，与页签本身的高度一致。
- 图标按钮统一为 30 × 30，图形使用 24 单位画布、统一笔画。修正设置、刷新、返回、主页等图标，并统一页签关闭按钮。数字列在表头和数据行中保持右对齐。
- 终端默认字号由 14 调整为 12px。设置中提供 8、9、10、11、12、13、14、15、16、18、20、24、28、32、36、40px。已有用户明确保存的字号继续保留。
- 进程区按进程名、CPU、内存展示紧凑表格；完整表格额外显示进程 ID 和用户。
- 端口区按协议、本地端口、状态展示紧凑表格；完整表格显示本地及远端地址、收发队列和所属进程。进程归属展示为名称和 PID，保留原始采集值。
- 两类表格均支持选中查看完整字段，刷新时按稳定标识保留选择；采集失败或格式错误时清除旧行并显示状态。表格使用虚拟化渲染，没有限制采集记录数量。
- HTML 设计稿同步字号、图标及结构化表格。

## 复现与验证

修复前的针对性测试已复现：图标按钮为 38 × 30、页签内容起点为 42、终端默认字号为 14。相关测试在修复后通过。

证据目录：`docs/evidence/ui-refinement/`。

- `regression.txt`：全模块 `go test -race -tags ci ./...`。
- `integration.txt`：隔离 Linux 服务器测试，额外用实际 ps/ss 输出验证结构化解析，并回归既有连接、传输和监控场景。
- `vet.txt`：Go 静态检查。
- `process-table.png`、`process-all-columns.png`、`port-table.png`、`port-all-columns.png`：真实 Fyne 控件在固定测试数据下的渲染图。
- `package.txt`、`SHA256SUMS`：打包记录与产物校验。

回归覆盖了多核 CPU 使用率超过 100%、带空格的进程名、IPv6 地址、没有进程归属的套接字、刷新排序变化、格式错误及采集失败。

## 当前运行实例

检查时发现现有客户端仍有活动 SSH 会话。打包脚本改为原子替换可执行文件，修复包不覆盖旧进程正在映射的程序文件；当前会话继续运行，新版在下次启动时生效。
