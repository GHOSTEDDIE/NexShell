# 终端助手

右上角打开“助手”，点击“新对话”，选择模型和本次可以访问的服务器。也可以不选服务器直接聊天。后续直接发送消息即可继续上下文；原有“运维任务”仍可用于明确目标、资源范围的任务。

助手可列出对话授权的服务器与当前打开的终端，主动连接已保存的服务器、读取终端输出，并在确认具体输入后向指定终端发送文字及换行。连接时沿用主机指纹确认和身份校验。不能凭模型生成的地址绕过连接范围。

操作当前终端会保留该终端的目录、环境变量和交互程序状态。发送消息时记录当前终端编号，工具调用与审批绑定服务器、终端编号及完整输入；切换标签不会更改已批准的目标。分屏通过焦点标识当前终端。关闭终端后旧编号失效。

输入发送成功仅说明交付完成，不能推断远端命令的退出状态。终端操作仍保存独立执行记录，未知交付结果停止本轮；同一调用编号不会重复输入。实际修复仍应通过独立只读检查验证。

普通聊天结束后回到就绪，可持续追问；授权默认 8 小时，退出应用保存对话并停止执行。需要扩大服务器范围时创建新对话。当前版本没有后台主动巡检或自主定时唤醒。

## 本次验证

- `go test -race -tags ci ./...` 通过。
- 确定性 Eino 模型连续两轮普通聊天，历史保留且回到就绪。
- `go test -race -tags integration ./tests/integration -v -count=1` 通过：真实 Linux SSH 终端中保留目录与环境变量；原有 SSH、文件传输、跳板、隧道、ZMODEM 和 Eino 审批修复验证场景通过。
- 本次没有调用用户配置的真实模型服务；模型自主选择工具的端到端效果仍需真实模型验证。

## DeepAgent

当前主助手基于 Eino DeepAgent，支持计划清单、独立上下文子任务和按服务器隔离的自动记忆。可以在助手菜单管理记忆；旧对话需要确认范围后恢复。参见 [DeepAgent 运行与迁移](deep-agent.md)。
