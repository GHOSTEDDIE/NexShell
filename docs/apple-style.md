# 苹果风格统一与菜单留白

## 界面变化

共享主题统一为中性灰层次、清晰的黑白文字和蓝色强调。浅色工作区使用白色内容区与浅灰侧栏；深色采用炭灰内容区及深灰分层。按钮、输入框、弹窗和浮层的圆角保持统一，Tab 使用蓝色下划线表达选中状态。按钮主色从共享主题读取；设置页的外观缩略图也反映实际配色。

复用现有四区布局、同步展开收起动效、字体缩放及中文字体资源。终端背景、前景和 ANSI 调色保持原有高对比设置。本轮调整的是 Fyne 应用的视觉风格，不是将整个应用改写为 AppKit。

## 操作菜单

文件右键与更多菜单、终端复制粘贴及更多菜单、连接右键菜单和助手更多菜单共用 `context_menu.go`：

- 菜单内容上下留白 7、左右 12 个逻辑单位，随界面字号比例缩放。
- 浮层距可交互窗口边缘至少 10 个逻辑单位；底部工具按钮触发时，空间不足则向上展开。
- 紧凑的行高、独立勾选列、圆角高亮与原有阴影。取消勾选后文字列保持位置，原菜单数据不被样式修改。
- 继续使用 Fyne 的 Menu 项、勾选、子菜单和键盘导航；外层使用标准非模态 PopUp，支持点击外部、Escape 关闭及恢复原焦点上下文。
- 菜单显示期间缩小窗口会重新调整位置。

原生文件选择器和系统主菜单继续采用操作系统 UI；设置页的普通选择框沿用 Fyne 行为并使用共享主题。

## 验证

记录在 `docs/evidence/apple-style/`：

- 菜单浅色/深色及 1.0/1.3 倍字号渲染、内外边距、底部向上展开、勾选列稳定、动作只执行一次、Escape、点击外部关闭和窗口缩放。
- 共享正文、辅助文字、状态文字、按钮及菜单选中文字的对比度回归。
- 完整工作台、外观设置及模型配置的浅深色预览，使用现有隔离测试数据；预览来自 Fyne 测试驱动，不是原生桌面实机截图。
- `go test -race -tags ci ./...` 与 `go vet -tags ci ./...`，包括原有设置导航、按钮尺寸、面板拖拽及动效回归。
- macOS 重新打包并验证签名。Windows/Linux 的视觉效果未实机验证。

未连接用户服务器或调用真实模型，未改变传输及 Agent 协议。
