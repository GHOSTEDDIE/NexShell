# 弹层动效与按钮比例

设置、服务器表单、新对话、操作确认、详情和信息提示使用共享弹层：打开时从下方 18 像素进入，时长 180 毫秒；关闭时短距离向下退出，时长 120 毫秒。使用减速曲线，没有弹跳或文字缩放，终端输入和流式文本不参与动效。

快速开关会停止旧动画并使已排队的旧帧失效。关闭期间避免重复响应，表单继续复用 Fyne 的字段校验，确认回调和关闭通知只执行一次。文件选择器继续使用原有 Fyne 控件。

设置页的保存、取消和完成按钮改为垂直居中，保持 30 像素高度、至少 72 像素宽度，避免被底部布局拉高。其他表单和确认弹层复用同样的操作行。

“设置 → 外观与显示 → 启用窗口动效”可关闭动效；同时遵循 Fyne 全局动画开关和 macOS“减少动态效果”。

验证：全项目并发回归和静态检查通过；单独验证动画中途关闭、快速重新打开、旧帧失效、关闭遮罩释放、禁止重复提交、无效表单不能确认以及设置按钮实际尺寸。亮色和暗色设置截图已检查。证据位于 `docs/evidence/motion-buttons/`。
