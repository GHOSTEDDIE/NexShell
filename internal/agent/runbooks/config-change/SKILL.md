---
name: config-change
description: 在修改服务器文本配置、修复配置错误或恢复配置备份时，使用读取、比对、保存和验证流程。
---

1. 用 `file_read` 读取目标绝对路径，记录原始内容及 `sha256`。确认变更与任务目标有关。
2. 描述要修改的配置项及预期效果；在授权范围外时申请本次文件变更。
3. 用 `file_write` 提交完整新内容与原始 `expected_hash`。保存成功的结果包含备份位置和写入后校验。
4. 若发生保存冲突，重新读取远端版本并分析差异，再形成新的修改请求。
5. 根据服务的实际能力执行配置检查；任意 Shell 检查通过具体请求授权。检查通过后才执行已授权的服务重启。
6. 再读取文件或服务状态，使用实际证据验证目标。恢复时读取备份内容，并对当前文件使用新的哈希执行 `file_write`，随后重复检查。
